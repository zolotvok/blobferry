## Wine ntdll patch (`patches/wine/`)

`0001-ntdll-skip-async-iosb-write-to-freed-memory.patch` is a source patch for Wine's `dlls/ntdll/unix` (`server.c`,
`unix_private.h`, `virtual.c`): it skips the store of a deferred async I/O result into a status block whose memory is
gone (seen with Watch Dogs 2). Wine is licensed under the GNU LGPL, version 2.1 or (at your option) any later version
(`COPYING.LIB` in the Wine tree; Wine's files carry that notice), and the patch, a modification of those files, is
offered under the same license (LGPL-2.1-or-later), not under the GPL of Blobferry's own code. Wine itself is not
included here; the patch is for a Wine/Proton build made elsewhere. Written without a Wine source tree at hand and
not built or tested yet.

## Not included

The vendor Mali Vulkan driver (`/vendor/lib64/hw/vulkan.mali.so`) is proprietary. Blobferry loads it from the
phone at run time and never ships, copies or redistributes it.

## Prior art

Running the phone's vendor Vulkan driver from a glibc Linux guest through libhybris is what tawc and
[ARLinux](https://github.com/taowen/arlinux-rootfs) do. Blobferry builds on that idea with its own ICD shim and a
compatibility layer for DXVK and vkd3d-proton on Mali.

[MaliBridge](https://github.com/ASEbrahim/MaliBridge) (GPL-3) runs the vendor driver for Linux programs too, through
a socket to an Android-side server. `MALI_COMPAT_GS_HIDE_PROCS` takes the idea of its "gs_hide": Mesa Zink turns
Xwayland's GL_QUADS into geometry shaders, which crash some Mali drivers, so geometry shaders are hidden from the
listed processes. MaliBridge's license is the same family as Blobferry's now, but only the idea was taken; Blobferry's implementation (a feature mask in the compat layer,
`src/compat/mali_compat_layer.c`) is its own, and no MaliBridge code is included.
